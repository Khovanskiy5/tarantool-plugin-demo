# tarantool-plugin-demo

Демонстрационный проект: каждая возможность плагина
[tarantool-idea-plugin](https://github.com/Khovanskiy5/tarantool-idea-plugin)
здесь «выстреливает» на подготовленных файлах.

Сценарий демонстрации по шагам — в [DEMO.md](DEMO.md).

Структура:

* `config.yaml` — кластер из роутера и репликасета (лидер + реплика):
  схема конфигурации, панель инстансов, автосоздание источников данных.
* `instances.yml`, `tt.yaml` — маркеры tt-проекта.
* `src/app.lua`, `src/model/` — код приложения: спейсы с format,
  box.once, файберы, триггеры, журнал, интеграция Emmy-отладчика.
* `src/api.lua` — функции для клиента по iproto; `src/model/queue.lua` —
  фоновые файберы-обработчики; `src/model/audit.lua` — триггер
  on_replace. На этих трёх файлах показывается графическая отладка:
  точка останова в файбере, в обработчике запроса и внутри триггера.
* `src/debug_setup.lua`, `src/inspect.lua` — включение отладчика из
  `config.yaml` и функция `D()` для панели Watches.
* `scripts/` — скрипты для конфигурации запуска «Tarantool»:
  hello, кликабельный трейсбек, встроенный отладчик, генератор
  нагрузки для отладки.
* `test/` — тесты luatest (раннер с деревом результатов).
* `playground/` — песочницы live-шаблонов и SQL-диалекта.
* `.run/` — готовые конфигурации запуска всех трёх типов.
* `docker-compose.yml` — заготовка для режима «Docker (tt в контейнере)».
